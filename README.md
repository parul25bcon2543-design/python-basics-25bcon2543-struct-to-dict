# Struct-to-Dict Converter

A simple Python program that converts a Student object into a dictionary.

## Features

- Creates a Student object.
- Stores student information such as name, roll number, and course.
- Converts the Student object into a dictionary.
- Displays the resulting dictionary.

## Requirements

- Python 3.x
- No external packages are required.

## Usage

Run the program using:

```bash
python struct-to-dict.pyStudent Dictionary:
{'name': 'Rahul', 'roll_no': 101, 'course': 'Python'}
